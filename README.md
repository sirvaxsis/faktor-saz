# فاکتورساز

سایت قابل نصب برای ساخت فاکتور و پیش‌فاکتور فارسی، گزارش و خروجی اکسل، با ذخیرهٔ محلی و اتصال به Supabase.

## اصلاحات این نسخه

- تغییر جدید هنگام ارسال تغییر قبلی از صف همگام‌سازی حذف نمی‌شود. شناسهٔ درخواست هنگام تلاش مجدد ثابت می‌ماند.
- همگام‌سازی، تغییرات در انتظار ارسال را نگه می‌دارد. تغییر ردشده در حساب کاربری قابل دانلود است و در پشتیبان محلی نیز می‌آید.
- خطای ذخیرهٔ مرورگر هشدار دائمی دارد؛ آخرین مقدار موقت در همان نشست قابل خواندن و خروجی گرفتن است. این حافظه با بستن صفحه از بین می‌رود.
- لوگو فقط تصویر raster با data URL معتبر است؛ شناسه‌ها و مقادیر واردشده هنگام نمایش HTML escape می‌شوند.
- برای فاکتورهای جدید، تخفیف متناسب میان اقلام توزیع و مالیات روی مبلغ پس از تخفیف محاسبه می‌شود. خروجی اکسل فاکتورهای قدیمی روش محاسبهٔ قبلی را حفظ می‌کند؛ ویرایش و ذخیرهٔ دوباره، روش جدید را اعمال می‌کند.
- پنل مدیریت موجود در بستهٔ به‌روزرسانی به سایت اضافه شده است؛ مجوز مدیر همچنان سمت سرور بررسی می‌شود.

## آزمون

آزمون‌های رگرسیون بدون وابستگی اضافه:

```sh
node --test tests/regression.test.cjs
```

آزمون مرورگری با API شبیه‌سازی‌شده، بدون تماس با پروژهٔ واقعی Supabase:

```sh
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
python tests/run_ui_tests.py
```

برای مرورگر Edge نصب‌شده در ویندوز، متغیر محیطی `PLAYWRIGHT_CHANNEL=msedge` قابل استفاده است.

این تست‌ها صحت SQL و RLS در دیتابیس واقعی، ایمیل واقعی یا دسترسی شبکه از ایران را تضمین نمی‌کنند. دیتابیس واقعی در این اصلاحات تغییر نکرده است.

## انتشار

پوشهٔ `site` منتشر می‌شود. GitHub Actions ابتدا تست‌های رگرسیون را اجرا و سپس نسخه را روی Pages منتشر می‌کند. نسخهٔ کش سرویس‌ورکر برای دریافت فایل‌های جدید افزایش یافته است.

تنها کلید عمومی Supabase باید در `cloud-config.js` قرار بگیرد. کلید مدیریتی، رمز دیتابیس و ابزار خصوصی تولید لایسنس را در سایت یا مخزن عمومی قرار ندهید.
